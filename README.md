# 📂 Auto File Organizer
A simple Python project that helps organize files into different folders based on their file types.

# ✨ Features
- Automatically organizes files by file extension.
- Creates folders for different file types.
- Helps keep directories clean and organized.
- Built using Python's built-in libraries.

## 🛠️ Technologies Used
- Python
- `os`
- `shutil`

## 🚀 How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:
   `python "automatic file organizer.py"`

## 🎯 Project Goal
This project was created to practice Python programming and file handling.
